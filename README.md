Stocky — A LangGraph-Powered Multi-Agent Stock Market Simulator

A LangGraph-powered multi-agent system that simulates a stock market and orchestrates four specialized AI agents over the simulated exchange. Agents share a common market state and pass context to one another as they analyze, decide, and act — collaborating the way a small trading desk might.

Overview

Stocky runs a simulated stock exchange with a live order matching engine, then lets four AI agents operate on top of it:

Market Analyst — reads the current market data and produces an analysis of trends and opportunities.
Risk Manager — evaluates proposed trades against portfolio exposure and risk limits.
Investor — makes the actual buy/sell decisions based on analysis and risk input.
AI Secretary — validates proposed trades, enforces business rules, logs activity, and generates portfolio reports.

The agents communicate through a shared state object and prompt passing rather than operating in isolation, so each decision reflects the upstream agents' reasoning.

Orchestration: LangGraph coordinates the multi-agent workflow as a graph of nodes, with shared state (shared_state.py) flowing between them.
LLM backend: Google Gemini API powers agent reasoning, with a validation/retry layer to handle malformed or rate-limited responses.
Simulated exchange: a custom order matching engine (stock.py) drives dynamic price movement based on submitted orders, rather than replaying static historical data.
Portfolio management: tracks holdings, cash, and P&L per run.
Reporting: financial summaries and activity logs generated by the AI Secretary agent (record.py, log/).

How it works
The simulated exchange (stock.py) generates and updates market prices via order matching.
Each simulated day, the Market Analyst and Risk Manager agents both read the current shared state — the Analyst producing a market read, the Risk Manager producing a risk assessment.
The Investor agent combines both inputs to decide on a trade (buy/sell/hold).
The AI Secretary agent validates the proposed trade against business rules before it's allowed to execute.
Approved trades are sent to the stock exchange for order matching, and the shared portfolio state is updated.
The AI Secretary agent logs activity and produces performance reports.
The simulation controller advances to the next day and the cycle repeats.

All of this is orchestrated as a LangGraph graph, so state moves between agents in a defined, inspectable sequence rather than through ad hoc function calls.
