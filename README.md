# Stocky — A LangGraph-Powered Multi-Agent Stock Market Simulator

A LangGraph-powered multi-agent system that simulates a stock market and orchestrates four specialized AI agents over the simulated exchange. Agents share a common market state and pass context to one another as they analyze, decide, and act—collaborating the way a small trading desk might.

---

## Overview

Stocky runs a simulated stock exchange with a live order matching engine and lets four AI agents collaborate on trading decisions.

### AI Agents

- **Market Analyst** – Reads current market data and identifies trends and opportunities.
- **Risk Manager** – Evaluates proposed trades against portfolio exposure and risk limits.
- **Investor** – Makes Buy/Sell/Hold decisions using market analysis and risk assessment.
- **AI Secretary** – Validates trades, enforces business rules, logs activity, and generates portfolio reports.

The agents communicate through a shared state object and prompt passing rather than operating independently, allowing every decision to incorporate upstream reasoning.

## Architecture

```text
           Simulation Controller
           (steps through each day)
                   │
                   ▼
             LangGraph Workflow
                   │
      ┌────────────┴────────────┐
      │                         │
Market Analyst          Risk Manager
      │                         │
      └────────────┬────────────┘
                   ▼
             Investor Agent
                   │
                   ▼
            Secretary Agent
      (Validation + Reporting)
                   │
                   ▼
          Stock Exchange Engine
                   │
      ┌────────────┴────────────┐
      │                         │
 Order Matching         Portfolio Update
      │                         │
      └────────────┬────────────┘
                   ▼
             Financial Reports
```

### Components

- **Orchestration** – LangGraph coordinates the workflow as a graph of nodes with shared state (`shared_state.py`).
- **LLM Backend** – Google Gemini powers agent reasoning with validation and retry logic.
- **Stock Exchange** – `stock.py` implements a simulated exchange and order matching engine.
- **Portfolio Management** – Tracks holdings, cash, and profit/loss throughout the simulation.
- **Reporting** – Financial summaries and logs are generated by the AI Secretary (`record.py`, `log/`).

## Getting Started

### Prerequisites

- Python 3.10+
- Google Gemini API Key

### Installation

```bash
git clone https://github.com/harshaggarwal9/Stocky.git

cd Stocky

pip install -r requirements.txt
```

### Configuration

Set your Gemini API key.

Linux/macOS

```bash
export GEMINI_API_KEY="your-api-key"
```

Windows (Command Prompt)

```cmd
set GEMINI_API_KEY=your-api-key
```

Windows (PowerShell)

```powershell
$env:GEMINI_API_KEY="your-api-key"
```

### Run

```bash
python main.py
```

## How It Works

1. The stock exchange updates market prices through the order matching engine.
2. The Market Analyst and Risk Manager evaluate the current shared state.
3. The Investor combines both analyses to make a Buy/Sell/Hold decision.
4. The AI Secretary validates the proposed trade.
5. Approved trades are executed by the stock exchange.
6. Portfolio state is updated.
7. Reports and logs are generated.
8. The simulation advances to the next trading day.
